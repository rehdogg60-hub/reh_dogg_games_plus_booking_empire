# Reh Dogg Games Plus: Booking Empire

A mobile-friendly browser prototype about running a fictional wrestling company as the head booker. Build feuds, manage heat and risk, protect wrestler morale, and keep the company profitable.

## How To Play

1. Start with `$100,000` in company money.
2. Pick exactly two fictional wrestlers from the roster.
3. Choose a feud type, angle style, feud length, and planned ending.
4. Book one weekly angle at a time.
5. Good booking raises heat and revenue. Risky or unpopular booking can hurt morale and cost money.
6. If company money reaches `$0`, the board fires you.
7. Finish a feud to receive a final rating, revenue report, and Booker Grade.

## Files

- `index.html` - Main game page.
- `style.css` - Arcade-management UI styling.
- `script.js` - Game data, feud logic, weekly booking, results, and audio hooks.
- `images/` - Generated fictional wrestler portraits and title background.

## Optional Audio

The game runs silently if audio files are missing. To enable sound later, place these files in the `sounds/` folder:

- `sounds/music_theme.mp3`
- `sounds/click.mp3`
- `sounds/crowd.mp3`

Music starts only after the first player click/tap, which keeps it compatible with mobile browsers.
