# Changelog

## Version 1.0 - Public Launch

Reh Dogg Games Plus: Booking Empire reaches its first public release as a complete arcade wrestling management experience.

### Launch Features

- Full title screen presentation with Version 1.0 and Free to Play branding.
- Startup splash and loading screen with rotating booking tips.
- Fictional 10-wrestler roster with portraits, stats, strengths, weaknesses, finishers, morale, contracts, and growth.
- Feud setup system with feud type, angle style, feud length, title feud option, and planned ending.
- Weekly TV show simulation with crowd reaction, segment ratings, commentary, morale changes, revenue, and backstage events.
- Championship system with RDGP World, Women's, Hardcore, and Tag Team titles.
- PPV / Big Event system with event names, match cards, title changes, event revenue, ratings, and grades.
- Rival promotions and ratings-war pressure.
- Contract, salary, morale, loyalty, and talent-poaching systems.
- News feed, world events, chaos/crisis events, sponsor and merchandise systems.
- Rankings, contender recommendations, tag teams, audience analytics, creative team advice, and tutorial/help screens.
- Hall of Fame and legacy tracking.
- Finisher preview clips with lazy-loaded MP4 playback.
- Local browser save/load with Continue Booking and Delete Save.
- Optional music and sound effects.
- Mobile-friendly responsive layout.

### Release Polish

- Neon arena atmosphere, scanlines, crowd glow, and animated screen transitions.
- Championship belt shine and prestige aura.
- Wrestler champion frames, breakout indicators, injury warnings, and momentum styling.
- Credits screen with scrolling arcade presentation.
- Release documentation for GitHub Pages and Ko-fi launch use.
